# Мобильное приложение для учета ОС (React Native / Expo) и интеграция с 1С:КА 2

Данный проект содержит готовое мобильное приложение для сканирования и инвентаризации Основных Средств (ОС) и код HTTP-сервиса для конфигурации 1С:Комплексная автоматизация 2.

## Структура проекта

* `1c_backend/InventoryAPI.bsl` — Код HTTP-сервиса на встроенном языке 1С.
* `mobile-app/` — Исходный код мобильного приложения на React Native (Expo).

---

## 1. Настройка на стороне 1С

### Шаг 1. Создание HTTP-сервиса
1. Откройте конфигуратор 1С.
2. В дереве метаданных найдите ветку **Общие -> HTTP-сервисы**.
3. Добавьте новый HTTP-сервис.
   - Имя: `InventoryAPI`
   - Корневой URL: `inventory_api`
4. Добавьте шаблоны URL и методы (скопируйте код из файла `1c_backend/InventoryAPI.bsl` в модуль HTTP-сервиса):
   * Шаблон: `/os/search`
     * Метод: `GET` (Обработчик: `ossearchGET`)
   * Шаблон: `/inventory/list`
     * Метод: `GET` (Обработчик: `inventorylistGET`)
   * Шаблон: `/inventory/sync`
     * Метод: `POST` (Обработчик: `inventorysyncPOST`)

### Шаг 2. Публикация базы на веб-сервере (IIS / Apache)
1. В конфигураторе выберите пункт меню **Администрирование -> Публикация на веб-сервере**.
2. Выберите веб-сервер (IIS или Apache).
3. Укажите имя публикации (например, `ka2`).
4. На вкладке **HTTP сервисы** поставьте галочку напротив `InventoryAPI`.
5. Нажмите **Опубликовать**.
6. Убедитесь, что веб-сервер запущен и брандмауэр позволяет подключения из локальной сети.

### Шаг 3. Создание пользователя для мобильного приложения
1. В режиме предприятия (или в конфигураторе) создайте нового пользователя (например, `mob_user`).
2. Задайте ему пароль.
3. Назначьте права: базовые права пользователя, права на чтение справочника "Основные средства", регистров "Штрихкоды", "Местонахождение ОС", "Состояния ОС", а также права на чтение и изменение документов "Инвентаризация ОС".

## 2. Настройка мобильного приложения

### Шаг 1. Запуск проекта
Для работы с проектом на вашем компьютере должен быть установлен [Node.js](https://nodejs.org/).

1. Откройте терминал и перейдите в папку приложения:
   ```bash
   cd mobile-app
   ```
2. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```
3. Запустите Expo-сервер:
   ```bash
   npx expo start
   ```

### Шаг 2. Тестирование на реальном устройстве
1. Установите приложение **Expo Go** на ваш смартфон (из App Store или Google Play).
2. Смартфон и компьютер должны находиться в одной Wi-Fi сети.
3. Отсканируйте QR-код из терминала с помощью камеры телефона (на iOS) или внутри приложения Expo Go (на Android).

### Шаг 3. Настройка подключения внутри приложения
1. На главном экране приложения нажмите **"Настройки подключения"**.
2. Введите URL базы 1С. Пример: `http://192.168.1.50/ka2/hs/inventory_api` (где 192.168.1.50 — IP вашего сервера с 1С).
3. Введите логин и пароль созданного пользователя 1С.
4. Нажмите **"Сохранить"**.

## 3. Использование приложения

* **Режим "Поиск оборудования"**: Позволяет отсканировать штрихкод ОС или вручную ввести инвентарный номер, чтобы получить карточку с информацией из 1С (МОЛ, Подразделение, Статус).
* **Режим "Инвентаризация"**:
  1. Нажмите "Инвентаризация", приложение запросит список непроведенных документов "Инвентаризация ОС".
  2. Выберите документ. Откроется экран сверки с плановым списком ОС.
  3. Включите сканер и сканируйте штрихкоды оборудования потоком.
  4. Приложение будет отмечать ОС зеленым (План+Факт), желтым (Излишек - найдено, но нет в плане этого документа) и красным (Недостача). Будет срабатывать вибрация.
  5. Нажмите "Отправить в 1С", чтобы зафиксировать фактическое наличие оборудования в выбранном документе.
